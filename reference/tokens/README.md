# Cian design tokens — исследовательский снимок

Дата: 12 ноября 2026. Источник: публичные CSS/JS source maps главной страницы cian.ru.
Это извлечённая часть `@cian/ui-kit-design-tokens` и foundations из `@cian/ui-kit`, а не устанавливаемый npm-пакет. Точные версии пакетов неизвестны. Авторство оригинальных ресурсов — Циан; публичная доступность не определяет условия лицензирования исходной библиотеки.

## Файлы

- `tokens.css` — базовая и семантическая палитры, градиенты. Удалены `@import`, синтаксис CSS Modules `:global(...)` преобразован в обычный CSS. Имена и значения сохранены.
- `tokens.json` — 526 переменных с `value`, `modes`, `resolved`, `package`, `sourceFile`, `sourceMap`. Это собственная схема выгрузки, не DTCG. Исходные алиасы не заменены итоговыми цветами.
- `foundations.css` — размерная сетка, переменные типографики и общий transition из `@cian/ui-kit`.
- `legacy.css` — устаревшая палитра отдельно. Для нового макета начинайте с актуальных семантических токенов.
- `source/` — оригинальные CSS-файлы пакета токенов, как они опубликованы в source maps. Эти файлы используют CSS Modules; напрямую подключайте подготовленный `tokens.css`.
- `icons/` — 24 SVG с простой структурой, извлечённых из исходных React-компонентов. Иконки со сложной вложенной структурой не конвертировались: их исходники есть в `../data/sources.json`.
- `manifest.json` — URL, SHA-256, границы снимка и неизвестные версии.

## Подключение

```html
<link rel="stylesheet" href="/cian/tokens/tokens.css">
<link rel="stylesheet" href="/cian/tokens/foundations.css">
```

```css
.feature {
  padding: var(--unit_6); /* 24px */
  color: var(--text-primary-default);
  background: var(--background-primary);
}
```

Режимы: `design-theme--light`, `design-theme--dark`, `design-theme--colored`, `design-theme--onOverlay`, `design-theme--system`. Класс рекомендуется задавать на `html`. По умолчанию действует light. System включает dark через `prefers-color-scheme: dark`; в JSON `resolved.system` соответствует тёмной ветке media query. Colored и onOverlay содержат прозрачные цвета и требуют подходящего фонового контекста.

Для точного вида потребуется Lato. Проверенные файлы 400/600/700 лежат отдельно в `../assets/fonts/`, подключение — в `../reference.css`. Они не входят в пакет цветовых токенов.

## Ограничения

Tree shaking оставляет только использованные модули. Снимок не доказывает полноту пакета. Например, отдельные универсальные токены радиусов не обнаружены; размеры скруглений прочитаны из стилей конкретных компонентов. `--unit_0` равен **2px**, а не нулю. Версии React не являются версиями UI kit.

Чтобы обновить закреплённый снимок из корня проекта: `python3 cian/scripts/extract.py --fetch`. Для перехода на новую сборку сначала проверьте свежие ссылки на сайте и явно обновите `ASSETS` и дату в скрипте.
