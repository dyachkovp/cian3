Как использовать в новых идеях

Подключите основу и проектируйте изменение внутри привычного визуального языка.

Подключение токенов

CSS работает без React и сборщика. Начните с семантических имён: они сохраняют смысл в разных темах.

<link rel="stylesheet" href="cian/tokens/tokens.css">
<link rel="stylesheet" href="cian/tokens/foundations.css">

.new-feature {
  color: var(--text-primary-default);
  background: var(--background-primary);
  padding: var(--unit_6);
}

Что делает интерфейс нативным

  • Используйте Lato и существующую шкалу текста: Body1 16/24, Body2 14/20.
  • Сохраняйте высоты контролов 36, 44 и 56 px и радиус 8 px.
  • Выбирайте цвет по роли: text, surface, control, stroke. У действия есть hover, pressed, focus и disabled.
  • Начинайте с привычных паттернов поиска и карточек. Новую функциональность добавляйте в их контекст.
  • Сверяйте макет с конкретной страницей: микрофронтенды могут использовать разные поколения компонентов.
Примеры JSX здесь описывают API обнаруженных компонентов. Установка приватного пакета не настроена: версия пакета и доступ к npm-реестру неизвестны.

Исходники и метод

Проверяемая основа для будущих обновлений, с датой и происхождением каждого файла.

Манифест ↓

Снимок охватывает код, который попал в бандл главной страницы. Он включает компоненты, внутренние утилиты и CSS. Неиспользуемые экспорты могли быть удалены при сборке.

Названия props и параметры типографики прочитаны из исходников. Примеры интерфейса используют извлечённые CSS-классы; интерактивность справочника реализована отдельно. Точные версии UI kit и design tokens не опубликованы в этих файлах.
