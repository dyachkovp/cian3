# Проверка аукциона: Нильсен и Норман

23 ноября 2026. Экспертная проверка учебного мобильного прототипа, не исследование с пользователями.
Основной сценарий и критерии: `tasks/auction/task.md`.

## Принципы Нормана

- Обнаруживаемость и сигналы: понятные подписи действий, поля с постоянными метками, нижние разделы «Главная», «Поиск» и «Мои объявления», вход продавца через «Разместить».
- Обратная связь: отправка блокирует повтор, затем показывает результат; публикация показывает опубликованные условия.
- Соответствие действий результатам: «Посмотреть объявление» открывает ту же квартиру, ставка меняет общую цену.
- Ограничения: недопустимая ставка не принимается, прошедшая дата не проходит проверку, условия после первой ставки не редактируются.
- Концептуальная модель: один аукцион, две стороны. Смена раздела меняет представление, сохраняя данные.

## Редактура

Применены принципы ясности и пользы из «Пиши, сокращай»: действие, условие, результат; без рекламных обещаний. Удалено обещание уведомлений, которых нет. Короткие союзы и предлоги связаны со следующим словом неразрывными пробелами.

## Критерии задания

- Продавец: главная → «Разместить» → «Продажа» → «Жилая» → «Квартира» → «Продать на аукционе» → условия → проверка → публикация → просмотр объявления.
- Покупатель: главная → квартира из рекомендаций (или через поиск) → условия в карточке → сумма → ожидание → принятая ставка.
- Низкая ставка показывает допустимую сумму; ошибка и завершение доступны через «Демо-состояния».
- При ошибке можно исправить сумму и повторить отправку. Завершённый аукцион не принимает ставки.
- Переход между ролями доступен через главную и раздел «Мои объявления», данные сохраняются в текущей вкладке. На создании доступен возврат к предыдущему выбору и выход через логотип.
- Оплата и юридическое оформление отсутствуют, как требует задание.

## Границы

Данные синтетические, запросов к серверу нет. Ошибка и завершение включаются для демонстрации; автоматическое завершение по часам не реализовано. Перезагрузка сбрасывает прогресс, разные вкладки не синхронизируются. Фото иллюстративные. Прототип реализован в браузере как мобильные экраны, без нативной сборки iOS/Android.
