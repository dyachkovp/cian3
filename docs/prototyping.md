# Как устроен прототип

## Маршруты и состояние

| Маршрут        | Назначение                                         |
| -------------- | -------------------------------------------------- |
| `/`            | Главная, поиск и рекомендации                      |
| `/search`      | Выдача, фильтры и сортировка                       |
| `/listing/:id` | Галерея, характеристики и локальная форма связи    |
| `/auction`     | Кликабельный сценарий продажи квартиры на аукционе |
| `/ui`          | Каталог общего UI-kit                              |
| `/patterns`    | Компоненты страниц и ссылки на состояния           |
| `/guide`       | Краткое руководство дизайнера                      |

`src/data/listings.ts` содержит тип `Listing`, восемь синтетических объявлений и чистую функцию фильтрации. Поиск — подстрока по названию, адресу, району и метро, а не семантический AI-поиск. Цены и площади демонстрационные. Фотографии взяты как визуальные референсы и не описывают синтетические объявления; кадры одной демонстрационной галереи могут относиться к разным объектам.

Параметры `q`, `rooms`, `maxPrice`, `sort`, `favorites=1` хранятся в URL. Пустая комнатность означает любую, `0` — студию. Сортировка: `default`, `price-asc`, `price-desc`, `area-desc`. Кнопка возврата из карточки сохраняет URL выдачи; прямой вход в карточку возвращает к общему поиску.

`PrototypeProvider` хранит избранное в `localStorage` (`cian3:favorites:v1`), предоставляет `showDemo(title)` для незапроектированных разделов и `notify(text)` для статуса действий. Недоступный или повреждённый storage не мешает работе приложения. Реальной отправки сообщений, авторизации, аналитики или запросов к API Циана нет.

## Аукцион квартиры

Маршрут `/auction` — главная мобильного прототипа Циана для задачи `tasks/auction/task.md`.
Продавец начинает через «Разместить» (`/auction/place`) → «Продажа» → «Жилая» → «Квартира» →
«Продать на аукционе» → условия → проверка → публикация. Первые три выбора повторяют структуру
пользовательских скриншотов мобильного приложения. Другие категории видны, но отключены вне сценария.
Данные квартиры подготовлены заранее, общий мастер заполнения объявления не входит в задачу.
Покупатель открывает квартиру из рекомендаций на главной или из поиска (`/auction/search`).
В карточке (`/auction/apartment`) под галереей, ценой и характеристиками находится блок аукциона.
«Мои объявления» (`/auction/seller`) открывает состояние собственника. После публикации
«Посмотреть объявление» ведёт к той же квартире со стороны покупателя. На широком экране
сохраняется мобильная компоновка шириной до 390 px. Нижняя навигация связывает главную, поиск и объявления;
в мастере размещения доступен выход через логотип и возврат на предыдущий шаг.

- Продавец задаёт стартовую цену, минимальный шаг и дату окончания, проверяет условия и локально публикует лот.
- Покупатель изучает карточку, вводит ставку и видит ожидание, принятую ставку, ошибку ответа и завершённый аукцион.

Цены, дедлайн и статусы ставок — детерминированные демонстрационные данные. Кнопки состояния нужны для ревью сценария; они не отправляют запросы и не относятся к правилам реального сервиса.

Обе роли используют общее состояние в пределах открытой страницы. Черновик, этап проверки,
опубликованные условия, сумма и статус ставки и завершение торгов сохраняются при переключении
ролей. Для прямого входа покупателя подготовлен пример активного аукциона. После публикации он видит
снимок условий продавца; первая ставка допускается от стартовой цены, следующая — от принятой
ставки плюс заданный шаг. Принятая ставка обновляет цену у обеих ролей, в том числе если во время
ожидания переключиться к продавцу. Ошибка не меняет цену. Пока ставок нет, условия можно изменить.
Во время отправки, после первой ставки и после завершения торгов редактирование заблокировано.
Дата окончания должна быть в будущем. Перезагрузка страницы сбрасывает сценарий; серверного хранения нет.
Кнопки «В начало прототипа» нет. Перезагрузка страницы начинает выбранный сценарий заново.
Общие данные живут в одной открытой вкладке; разные вкладки и сервер не синхронизируются.
Ошибку и окончание торгов можно воспроизвести через раскрываемый блок «Демо-состояния».

Визуальная адаптация сохраняет логотип, Lato, семантические токены и синий основной акцент Циана.
Крупные суммы, мягкие поверхности и лаконичная композиция — учебная интерпретация запроса на
эстетику Revolut, а не официальный интерфейс мобильного приложения Циана.
Галерея использует локальные иллюстративные фото Unsplash; они могут относиться к разным квартирам
и не подтверждают характеристики синтетического лота. Источники: `public/images/auction/sources.md`.

## Композиции

| Компонент        | Использование                                                                 |
| ---------------- | ----------------------------------------------------------------------------- |
| `AppShell`       | Header + содержимое + Footer; один раз на продуктовую страницу                |
| `PageLayout`     | Контейнер с `children` и необязательным `aside`; на телефоне одна колонка     |
| `Breadcrumbs`    | `items: {label,to?}[]`                                                        |
| `ListingCard`    | `listing: Listing`, `compact?: boolean`; общее избранное и переход в карточку |
| `SearchBar`      | Поиск с главной                                                               |
| `SearchFilters`  | `params: URLSearchParams`, `onApply(next)`                                    |
| `Sorting`        | `value`, `onChange(value)`                                                    |
| `Gallery`        | `images`, `title`; выбор кадра и диалог просмотра                             |
| `ListingActions` | `listing`; цена, продавец и локальная форма                                   |
| `PrototypePage`  | Шаблон нового сценария с `title`, `description?`, `children`, `aside?`        |

## Проверка состояний

- `/search?state=loading` — постоянный skeleton для ревью.
- `/search?state=empty` — пустая выдача.
- `/search?q=Сокольники&state=error` — ошибка; повторная попытка сохраняет фильтры.
- `/search?q=НесуществующийРайон` — естественная пустая выдача.
- `/search?favorites=1` — пустое или заполненное избранное.
- `/listing/unknown` — неизвестное объявление.

Обычная выдача использует небольшую демонстрационную задержку 280 мс. Маршрут `/patterns` даёт доступ ко всем состояниям без редактирования кода.

## Границы готовности

Это основа для новых кликабельных сценариев. Карта, ипотека, личный кабинет, размещение объявления, сравнение и серверная отправка не реализованы. Они дают локальный демонстрационный ответ. Задание участников (например, размещение или новый тип объявления) не решено заранее. Базовое приложение светлое; тёмный режим проверяется в каталоге UI-kit.
